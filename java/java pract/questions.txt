# 🟢 LEVEL 1 – Basic Methods (static / non-static)

1️⃣
Create a Java application where we have **1 class** it contains:

* 1 non-static method having **int parameter and int return type**
* 1 static method having **no parameters and no return type**
  Invoke the non-static method inside static method and static method inside main method using **dynamic inputs**.

---

2️⃣
Create a Java application where we have **1 class** it contains:

* 1 static method having **two int parameters and int return type**
* 1 non-static method having **no parameters and no return type**
  Invoke static method inside non-static method and print the result.
  Call non-static method inside main using object.

---

3️⃣

* 1 non-static method having **float parameter and boolean return type**

  Invoke non-static method inside static method.
  Call static method inside main by creating object dynamically.

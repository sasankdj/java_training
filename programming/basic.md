## 1. Kg to Grams Conversion

**Example:**  
Input: `5.6 kg`  
Output: `5600 grams`

## 2. Celsius to Fahrenheit Conversion
Write a program to convert temperature from Celsius to Fahrenheit.  

**Example:**  
Input: `80°C`  

**Formula:**  
(80 × 9/5) + 32 = 176°F  

Output: `176°F`

## 4. Conditional Number Program
Write a Java program that performs the following tasks:

- Store a number in a variable.
- If the value is not in the range **100–1000**, print `"Wrong Number"`.
- Otherwise:
  - Check whether the number is **even or odd**.
  - If **even**, divide the number by 3 and print the remainder.
  - If **odd**, divide the number by 2 and print the remainder.

---

## 5. Smartness Grade Program
Declare and initialize a number.

- If the number is not in the range **0–100**, print `"Invalid Input"`.
- Otherwise, print according to the range:

| Range  | Output         |
|--------|---------------|
| 91–100 | Super Smart   |
| 81–90  | Smart         |
| 71–80  | Smart Enough  |
| 61–70  | Just Smart    |
| 36–60  | Not Smart     |
